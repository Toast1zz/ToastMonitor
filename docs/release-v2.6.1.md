## Fixed

- Your menu bar font, usage period and quota alert settings now stay as you set them after ToastMonitor restarts.
- Today's numbers roll over at midnight and after your Mac wakes from sleep, instead of waiting for the next scan.
- Closing the Dashboard no longer hides an open Settings window.
- A rare crash when moving the pointer over a chart is fixed.
- With seven or more OpenRouter keys, ToastMonitor no longer freezes while refreshing them.
- Renewal reminders for subscriptions you deleted no longer show up.
- If restoring a backup fails, your previous data is now put back as it was.
- Updates are checked more strictly: a new version must be signed by the same developer as the one you have installed before it replaces it.
