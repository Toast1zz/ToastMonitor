## Improved

- Performance page layout redesigned: provider filters now sit as compact pills in the chart header (click to toggle, Option-click to isolate) instead of stacked checkboxes, keeping the model legend clean and unclipped.
- Filtering by provider now updates the summary cards, chart, legend, and Details table together.
- Hovering or clicking a model in the legend or table highlights its line in the chart, and the Details table adds Provider and TTFT P90 columns plus CSV export.
- Performance now refreshes automatically when new scans arrive, caches range queries, and includes sample data in Demo Mode.
