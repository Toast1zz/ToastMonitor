Lowers collector memory: large transcript scans now release their temporary read buffers after every read instead of holding them until the whole scan finishes, cutting peak memory of a synthetic 46 MiB scan from about 56 MiB to 9 MiB without changing token totals, event identity or cursors. Adds a reproducible memory benchmark (`scripts/benchmark-memory.py`). Thanks to @yeyebbc for the contribution (#4).
