## Fixed

- **Plans Page & Accounts Management**: Redesigned `PlansView` into a clean two-column native layout (`Quotas` on the left, `Balances`, `Subscriptions`, and `Not connected` on the right) with uniform row alignment, Codex quota support, semantic 80%/90% usage thresholds, time-pace bars, live 60s countdown updates, and concise `RowProblem` error handling with deep-links into `Settings › Accounts`.

- **Menu Bar Popover**: Loaded `hide_quota_row_*` visibility flags synchronously on initialization and on panel reopen so hidden accounts stay hidden, fixed the `$$` formatting bug on Command Code credit balance, restored critical quota bar alerts, added heatmap hover readouts and cached week grids, added in-place Hero format and Quota `Used / Remaining` toggles, and made header status clickable to open `Settings › Sources`.
- **Dashboard Performance & Usability**: Eliminated synchronous `Database.shared` queries from SwiftUI `body` across `OverviewView`, `PlansView`, and `PopoverHomeView` by preloading OpenRouter and DeepSeek samples into `UsageQueryService.LightSnapshot` / `AppState`; moved `OverviewView` heatmap rendering to `Canvas` with isolated hover state; added `⌘R` refresh, toolbar busy state, `UsageAnalysisView` table sorting and background aggregation, and `SessionsView` search, sorting, turn token breakdown, and `Copy ID`.
- **Design System**: Added `DESIGN.md` documenting ToastMonitor's native macOS design redlines and `--build-system native` visual verification workflow.
